Earn It Grow It Uploader

This is a private tool used only by the owner of the Earn It Grow It YouTube channel, a channel of short explainer videos about earning, saving and investing money.

The tool uploads the channel owner's own finished videos to the owner's own YouTube channel and schedules them for publication. It sets each video's title, description, thumbnail, captions and publish time. It is not a public service: nobody else can sign up for it or use it with their account.

How it uses YouTube

  • The owner signs in once with Google and grants access to their own YouTube channel.
  • The tool uses the YouTube Data API only to upload videos, set thumbnails and captions, and schedule or update the owner's own videos.
  • It does not read, collect or store data about viewers or any other users.
